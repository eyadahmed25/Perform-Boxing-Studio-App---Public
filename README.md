Perform Boxing Studio Mobile App

	Train hard. Stay organized. All in one app.

Repository Note -  Code is not publicly accessible, but this README documents the full project scope, architecture, and development process.

The Perform Boxing Studio App is a production-level mobile application built to digitize and enhance the member experience at Perform Boxing Studio, a premier boxing gym in Abu Dhabi, UAE. The app streamlines membership management, session scheduling, payments, and community engagement for both members and staff.

This project was conceptualized in December 2024 and officially launched on the App Store and Google Play after 7 months of full-cycle development.

Project Background

The idea originated from identifying inefficiencies in how gym members booked sessions, managed memberships, and interacted with staff. The goal was to create a centralized digital platform that:
	•	Simplifies scheduling and bookings
	•	Improves training organization
	•	Strengthens community engagement
	•	Reduces administrative overhead

This was the team’s first full mobile application, developed while balancing university commitments across different countries through remote collaboration.

Technology Stack

Frontend

	•	FlutterFlow (built on Flutter & Dart)

Although FlutterFlow is a relatively new platform, this project goes far beyond drag-and-drop usage, implementing complex workflows, logic, and production-grade UI/UX.

Backend & Services

	•	Firebase (Authentication, Database, Hosting)
	•	Stripe API for secure payment processing

App Features

Member Features

	•	User registration and profile management
	•	Membership purchase and renewal
	•	Class booking and personal training scheduling
	•	Secure payments via Stripe
	•	Boxing gear and merchandise shopping

Admin Features

	•	Class creation and management
	•	Attendance and booking tracking
	•	Personal training schedule oversight
	•	Membership and payment management
